

<!-- Boostrap classes -->

🧱 1️⃣ Container & Grid System
🔹 Containers

| Class                     | Description                                                                                                      |
| ------------------------- | ---------------------------------------------------------------------------------------------------------------- |
| `.container`              | Fixed-width container (responsive breakpoints).                                                                  |
| `.container-fluid`        | Full-width container across entire viewport.                                                                     |
| `.container-{breakpoint}` | Responsive containers like `.container-sm`, `.container-md`, `.container-lg`, `.container-xl`, `.container-xxl`. |
